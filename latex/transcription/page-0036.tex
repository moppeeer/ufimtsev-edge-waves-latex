\[A_x=\frac i2H_{0z}\cdot I_1,\quad A_y=A_z=0,\tag{3.08}\]

\[I_1=\int_0^\infty e^{-ik\xi\cos\phi_0}H_0^{(1)}\left(k\sqrt{y^2+(x-\xi)^2}\right)d\xi.\tag{3.09}\]
Let us transform it by using the relationship
\[\begin{gathered}H_0^{(1)}\left(k\sqrt{d^2+z^2}\right)=\frac1\pi\int_{-\infty}^{\infty}\frac{e^{i(vd-wz)}}v\,dw\\(v=\sqrt{k^2-w^2},\ \operatorname{Im}v>0,\ d>0).\end{gathered}\tag{3.10}\]
It is not difficult to establish the correctness of this relationship by verifying that it changes into Expression (3.04) with the substitution $w=k\sin t$, $v=k\cos t$ and $k\sqrt{d^2+z^2}=\rho$. As a result
